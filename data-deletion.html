データ削除リクエスト

アプリ「AI囲碁 〜AIを育てて対局〜」(com.domgrp.igo_ai_app)

1. アプリで取り扱うデータ

データ種類保存場所保持期間
作成したAIの情報（名前、棋風、レベル、対局統計） お使いの端末内（SharedPreferences） アプリのアンインストールまで
匿名認証ID (Firebase Authentication) Firebase アンインストール後も残存。リクエストで削除可
オンライン対戦の対局データ（棋譜、参加AI名） Cloud Firestore 対局終了から最長90日（自動的に管理運用範囲内で削除）
マッチング待機キュー Cloud Firestore マッチ成立または10分経過で自動削除

2. データを自分で削除する方法

2.1 端末内データ

本アプリをアンインストールすると、端末に保存されている全てのデータ（作成したAI、対局統計、育成回数の記録）が完全に削除されます。アプリ内設定の「すべてのデータを削除」ボタンからも同様に削除できます。

2.2 サーバー上のデータ

Firebase 上に残る匿名アカウントとオンライン対局データの削除をご希望の場合は、下記メールアドレスまでご連絡ください。

support@dom-grp.com にメールで連絡

メール本文に以下の情報を記載いただくと、迅速な対応が可能です。

  • 件名: 「AI囲碁 データ削除リクエスト」
  • アプリ内で表示されているAI名（任意）
  • その他、ご本人特定のための情報（任意）

3. 削除されるデータ

  • Firebase Authentication の匿名アカウント（UID）
  • Cloud Firestore 上のあなたに紐づく対局データ
  • Cloud Firestore 上のあなたに紐づくマッチング情報

4. 保持されるデータ

  • 対戦相手として残る対局データ内のAI名（個人特定不可能な形での記録）
  • システム運用上必要な統計データ（個人特定不可能な形での記録）

5. 処理期間

ご連絡いただいてから、おおむね10営業日以内に削除を完了し、メールでご連絡いたします。
